# 计量设置

> 计量中心 → 计量设置 · 需要 <span class="ap-badge admin">admin</span>

配置汇率及成本计算规则。分两个页签：**货币与汇率** 和 **成本规则**。

## 货币与汇率

### 币种设置

| 字段 | 说明 |
|---|---|
| 基准币种 | 用于把不同模型和供应商的成本**归一**为统一货币 |
| 默认展示币种 | 只影响前端展示，**不修改原始费用** |
| 金额显示精度 | 前端展示的小数位数；后端始终保留高精度 |
| 保留原始费用 | 保留调用的原始金额、币种及汇率快照（**始终开启**） |

::: tip 原始金额永远不会被改写
展示币种和精度只是「看」的方式。每条费用记录都保存了原始金额、原始币种与当时的汇率快照，历史账单可追溯、可复算。
:::

### 汇率管理

维护币种对的换算关系：

| 字段 | 说明 |
|---|---|
| 币种对 | 原始币种 → 目标币种 |
| 汇率值 | 换算系数 |
| 来源 | 手动维护 / 系统默认 |
| 状态 | 启用 / 停用 |
| 生效时间 / 失效时间 | 汇率的有效区间 |
| 备注 | 说明来源与依据 |
| 更新人 / 更新时间 | 审计信息 |

操作：**添加汇率** · **编辑** · **停用** · **历史**。

::: warning 停用汇率不影响已产生的账单
确认停用时会提示「已产生账单不受影响」—— 历史记录用的是当时的汇率快照。
:::

**汇率历史**保留每一次变更的版本，可随时回看某个时点用的是哪个汇率。

### 换算验证

底部提供一个小工具：填金额 + 原始币种 + 目标币种，选一个汇率，即时看到换算结果。**换算验证只用于确认配置，不创建任何账单。**

## 成本规则

### 价格缺失处理

当模型未配置价格时如何处理费用计算：

| 选项 | 行为 |
|---|---|
| 标记为价格待配置，调用继续 | 不阻断业务，费用留空待补 |
| 按 0 临时计算并产生告警 | 费用记 0，同时告警提醒补价格 |
| 拒绝生成费用记录 | 不生成该条费用记录 |

::: tip 推荐「标记为待配置」
业务不受影响，同时能在计量中心一眼看出哪些模型缺价格。补上单价后重新统计即可。
:::

### 缓存 Token 计算

分别开关：**计算缓存读取 Token**、**计算缓存写入 Token**。是否把缓存命中产生的 token 计入费用，取决于上游供应商的计费口径。

### 金额舍入规则

四舍五入 / 向上取整 / 向下取整。

### 月末费用预测

| 选项 | 算法 |
|---|---|
| 按当月日均线性预测 | 当月累计 ÷ 已过天数 × 当月总天数 |
| 按最近 7 天日均预测 | 近 7 天日均 × 当月总天数 |
| 不显示预测 | 隐藏仪表盘与计量中心的预测值 |

### 告警设置

四类开关：

- **价格缺失告警** —— 有模型没配单价
- **汇率缺失告警** —— 需要换算但没有对应汇率
- **月度预算告警** —— 接近或超出预算
- **用量异常增长告警** —— 用量陡增

告警会汇总到总览仪表盘的「异常与待处理事项」。

## 配置建议

| 场景 | 建议 |
|---|---|
| 单一币种、内网自建模型 | 基准与展示币种一致；价格缺失选「标记为待配置」 |
| 多供应商、多币种 | 认真维护汇率与生效区间；开启汇率缺失告警 |
| 需要向财务出账 | 精度设到 4 位以上；开启月度预算告警；月末用「按当月日均」预测 |
