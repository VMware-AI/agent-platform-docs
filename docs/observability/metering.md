# 计量中心

> 可观测性 → 计量中心 · <span class="ap-badge admin">admin</span> <span class="ap-badge readonly">read_only</span>

按时间范围汇总网关调用量、Token 消耗与成本估算，支持按智能体与模型下钻。这是回答「这个月花了多少、花在谁身上」的地方。

## 数据源：平台记录 vs 网关记录

页面顶部可切换**数据源**：

| 数据源 | 来自 | 特点 |
|---|---|---|
| 平台记录 | 控制面自己的请求日志 | 带智能体归属、可与实例关联 |
| 网关记录（litellm） | 直接从各网关聚合 | 与网关账单口径一致，权威 |

::: tip 两个口径对不上时
先用「网关记录」为准 —— 它是计费源头。平台记录可能因为采集延迟或实例已回收而略有差异。
:::

**网关记录**由后端向各网关 fan-out 聚合（各自用自己的 master key），前端不直连任何网关。

## 时间范围与筛选

- **时间范围**：过去 7 天 / 过去 30 天 / 本月 / 自定义范围（起、止）
- **筛选**：智能体 ID、模型；也可选「全部智能体」「全部模型」

## 汇总指标

顶部四个数字：

| 指标 | 说明 |
|---|---|
| 总花费 | 折算到展示币种后的金额 |
| 总 Token | 输入 + 输出 |
| 输入 Token | prompt tokens |
| 输出 Token | completion tokens |

另有 **活跃智能体** 与 **活跃模型** 两个计数。

## 维度视图

「按…」维度可切换：

| 维度 | 用途 |
|---|---|
| 按部门 | 部门级成本分摊 |
| 按模型 | 哪个模型最贵 |
| 按密钥 | 哪把密钥消耗最多 |
| 按智能体 | 哪个人 / 哪台机器用得最多；未关联的记入「未归属」 |

每个维度提供：**花费趋势**折线、**花费排行 Top 5**、以及明细表（名称 / 花费 / 总 Token / 输入 / 输出）。

## 图表

| 图表 | 内容 |
|---|---|
| Token 使用趋势 | 按日 / 周 / 月的走势 |
| Token 使用排名（按智能体） | 智能体消耗排行 |
| 模型用量分布 | 各模型占比 |
| Token 使用排名（按模型） | 模型消耗排行 |
| 每日趋势 · 输入/输出占比 | 下钻到单个模型时展示 |

## 下钻

- 点表格里的智能体或模型进入**下钻页**，看该对象的独立趋势与明细
- 点「按智能体 × 模型」的组合进入**组合详情页**，看某个智能体在某个模型上的消耗

三张统计表可切换：**按智能体** / **按模型** / **按日期**。

## 成本估算摘要

底部给出总计金额与**月份预计成本**。预测口径可在[计量设置](/observability/metering-settings)里切换：

- 按当月日均线性预测
- 按最近 7 天日均预测
- 不显示预测

## 导出

点 **导出 CSV** 导出当前筛选范围的数据。当前无数据时会提示「当前无数据可导出」。

## 常见问题

| 现象 | 处理 |
|---|---|
| 无数据 | 放宽时间范围；确认筛选没过窄；点「重置筛选」 |
| 有 Token 但花费为 0 | 模型未配置单价 → [模型管理](/console/models)补价格 |
| 大量记录归到「未归属」 | 这些调用的密钥没有绑定智能体，或实例已彻底删除 |
| 平台记录与网关记录差异大 | 检查请求日志采集是否正常（otel-collector 容器状态） |
