# 规格与限制

一页集中所有默认值、上限与命名规则，配置前先扫一眼，能省掉不少试错。

## 命名与格式约束

| 对象 | 规则 | 可否修改 |
|---|---|---|
| **模型名称** | 大小写字母、数字、中划线与点，2–64 字符 | ❌ 创建后不可改 |
| **路由名称** | **大写字母**、数字与中划线，2–64 字符 | ⚠️ 可改，但会让引用它的 agent 立刻失效 |
| **Skill 标识** | 仅小写字母、数字和短横线 | ❌ 创建后不可改 |
| **agent 版本号** | `^[A-Za-z0-9_][A-Za-z0-9_.-]{0,127}$` —— 不含路径分隔符、空格、shell 元字符 | — |
| **用户名 / 邮箱** | 平台内唯一，输入时实时校验 | 用户名不可改 |
| **密钥名称** | 平台内唯一 | 可改 |
| **供应商模型 API Key** | 加密入库，前端永不回显 | 留空 = 保持原值 |

## 密码策略

### 平台账号

| 规则 | 值 |
|---|---|
| 最小长度 | 12 |
| 必含 | 大写字母、小写字母、数字 |
| 自动生成的初始密码 | **只显示一次**，关闭弹窗后无法找回 |
| 默认管理员 | `admin@platform.local` / `.env` 的 `ADMIN_BOOTSTRAP_PASSWORD`（默认 `ChangeMe123!`） |

### 智能体 VM 账号

| 规则 | 值 |
|---|---|
| 策略 | 由平台侧下发（长度下限、字符要求、最大字节数） |
| 新密码 | 不能与当前密码相同 |
| 改密方式 | [VM 自服务管理台](/agent-vm/webadmin)，OS + Web 事务式同步更新 |
| 失败节流 | 连续失败会被限流（HTTP 429） |
| **自动轮换** | 默认 **30 天** —— 上次轮换超过该周期时，心跳会排队一条 UI 密码轮换命令；同一时刻只允许一条在飞 |

::: tip 30 天自动轮换是默认行为
它不需要你配置任何东西。使用者会在到期后被要求改密 —— 提前告知，免得当成故障来报。
:::

## 会话

| 项 | 值 |
|---|---|
| 会话有效期 | `SESSION_TTL_SECONDS`，默认 **28800 秒（8 小时）** |

## 导出

| 项 | 值 |
|---|---|
| 支持导出的页面 | 智能体实例 · 请求日志 · 审计日志 · 计量中心 |
| 格式 | CSV |
| **单次导出上限** | **5000 条** |
| 内部分批 | 每批 500 条 |
| 超限提示 | 「数据较多，已导出前 N 条」 |
| 无数据提示 | 「当前无数据可导出」 |

::: warning 要全量数据就分段导
5000 条是硬上限。一个月的请求日志通常远超这个量 —— 按天或按周切分时间范围，分批导出后再合并。
:::

## 虚拟密钥

| 字段 | 取值 |
|---|---|
| 有效时长单位 | 小时 h / 天 d / 周 w / 月 m；**留空 = 永不过期** |
| 轮换周期单位 | 秒 s / 分钟 m / 小时 h / 天 d |
| 可调用接口 | `CHAT` / `EMBEDDINGS` / `IMAGES` / `AUDIO`；不选 = 全部 |
| 可调用模型 | 不选 = 全部 |
| 限流模式 | `guaranteed_throughput`（保量）/ `best_effort`（尽力） |
| 状态 | 启用 / 禁用 / 已吊销 |
| 清理密钥 | 按天数清除已吊销的令牌，永久删除 |

## 智能体实例

| 项 | 约束 |
|---|---|
| CPU 核数 | 1 – 上限；**运行中仅可扩容** |
| 内存 | 1 GB – 上限；运行中仅可扩容 |
| 磁盘 | 下限 – 上限；**任何状态下只能扩容** |
| 缩配 | CPU / 内存需先停止实例；磁盘无法缩 |
| 异常状态 | 不支持打开配置面板 |
| 克隆模式 | 全量 `full` / 即时 `instant`（即时需父虚拟机） |
| 状态流转 | 部署中 → 运行中 / 异常；删除 → 已回收 → 彻底删除 |

## 模型与路由

| 项 | 取值 |
|---|---|
| 供应商分类 | `custom` / `openai` / `anthropic` / `deepseek` / `minimax` / `moonshot` / `openrouter` |
| 模型健康 | 健康 `full_healthy` / 降级 `partial_outage` / 熔断 `full_outage` / 未探测 `unknown` |
| spec 健康 | `healthy` / `unhealthy` / `unknown` |
| 路由策略 | 简单洗牌 / 最闲优先 / 延迟优先 / 使用率优先 / 成本优先 |
| 降级链 | 常规故障转移 / 上下文超限降级 / 内容策略降级 |
| 限流类型 | Token 限制 / 请求数限制 / 组合限制 |
| 计费单价 | 输入 / 输出 / 缓存读取 / 缓存写入，四项独立 |

::: danger 熔断不会自动恢复
`full_outage` 会**拦截新请求**，必须手工「解除熔断」。
:::

## 需要手工输入名称才能确认的操作

这些操作不可撤销，界面强制二次确认：

| 操作 | 需输入 |
|---|---|
| 删除资源池 | 资源池名称 |
| 删除模型网关 | 网关名称 |
| 删除 OVA 模板族 | 模板名称 |
| 删除用户 | 用户名 |
| 删除密钥 | 密钥名称 |
| 批量删除密钥 | `DELETE` |

::: tip 这不是繁琐，是刹车
上面每一项都会连累其他对象：删资源池 = 其上实例失去管理通道；删网关 = 其下模型 / 路由 / 密钥全部失去归属。多敲一次名字，换的是不用连夜重建。
:::
