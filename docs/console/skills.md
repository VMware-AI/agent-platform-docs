# 技能管理

> 智能体中心 → 技能管理 · 需要 <span class="ap-badge admin">admin</span>

统一管理 OpenClaw、OpenCode、Hermes 等智能体可使用的技能与能力扩展。技能以离线包的形式存放在跳板机仓库，再批量安装到智能体 VM —— 全程不需要 VM 有外网。

## 页面结构

顶部统计：**总技能** · **当前显示** · **已选中**。工具栏支持按分类、状态筛选与关键字搜索。

列表列：Skill · 描述 · 分类 · Agent · 版本 · 安装方式 · 状态 · 操作。

分类内置：开发 · 运维 · 办公 · 安全 · 数据 · AI。状态：已启用 / 已停用。

## 新增 Skill

点 **新增 Skill**，表单分四段：

### 基础信息

| 字段 | 说明 |
|---|---|
| Skill 标识 | 仅小写字母、数字和短横线，**创建后不可修改** |
| Skill 名称 | 显示名 |
| 描述 | 用途说明 |
| 分类 | 开发 / 运维 / 办公 / 安全 / 数据 / AI |
| 适用 Agent | 该技能可安装到哪些 agent 类型 |

### 安装信息

| 字段 | 说明 |
|---|---|
| 安装方式 | Python 包（pip）/ NPM 包 / 二进制程序 |
| 源包 URL | 上游包地址 |
| 版本 | 包版本 |

### 离线包部署

这是关键一段 —— 决定 VM 能不能真的装上。

| 字段 | 说明 |
|---|---|
| 离线仓库地址 | Agent VM 通过此地址下载离线包；同步 / 上传后的包会存到这里 |
| 离线包 URL | 仓库中的实际包地址 |
| 本地上传 | 选择本地 `.tar.gz` 上传到跳板机 |

两种入库方式：

- **在线下载** —— 填源包 URL 后点「在线下载」，后端下载并推送到跳板机离线库
- **上传到离线库** —— 直接从本地上传 `.tar.gz`

表单会给出就绪状态提示：

- ✓ 离线包已就绪：`<url>`
- ⚠ 离线包尚未同步到跳板机，部署时无法安装

::: warning 没入库就等于装不上
只填了源包 URL、没有执行「在线下载」或「上传」，包并不在跳板机上。此时安装到 VM 会失败。发布前一定要看到「✓ 离线包已就绪」。
:::

### MCP 配置（可选）

需要以 MCP Server 形式暴露的技能在这里配置。

## 安装到智能体

两个入口，效果相同：

- **技能管理页** → 某个 Skill 的「安装到 Agent」
- **智能体实例页** → 某台实例的「安装 Skill」

安装对话框会：

1. 列出**离线包**清单（显示「离线包 N 个」）
2. 检查每个包在该 agent 上的**已安装 / 未安装**状态
3. 勾选后点「安装 N 个 Skill」
4. 完成后汇总「安装完成: N/M 成功」

也可以在 Skill 表单里直接填 **Agent IP 地址** —— 后端会自动 SSH 到该 agent 安装离线包。

::: tip 对话框提示「暂无可用离线 Skill」
说明离线库里还没有任何已就绪的包。先在技能管理里同步或上传。
:::

## 其他操作

| 操作 | 说明 |
|---|---|
| 编辑 | 改名称、描述、分类、适用 Agent、安装信息（标识不可改） |
| 删除 | 从平台移除该技能登记 |
| 刷新 / 重新加载 | 重新拉取列表 |
| 清除筛选条件 | 一键复位筛选 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 安装失败 | 确认离线包已就绪；确认 agent VM 能访问「离线仓库地址」；确认目标 agent 类型在「适用 Agent」里 |
| 在线下载失败 | 后端（不是 VM）需要能访问源包 URL；离网环境请改用本地上传 |
| 列表为空 | 还没创建任何 Skill，或筛选条件过窄，点「清除筛选条件」 |
| 标识填错了 | Skill 标识创建后不可修改，只能删除重建 |
