# 平台设置

> 系统配置 → 平台设置 · 需要 <span class="ap-badge admin">admin</span>

管理平台许可与外观个性化配置。页面有两个页签：**许可管理**（默认）与 **个性化设置**。

## 许可管理

平台默认提供 **90 天试用**。正式许可与**首个接入资源池的 vCenter IP** 绑定，凭该 IP 向厂商申请。

### 状态面板

| 字段 | 说明 |
|---|---|
| 模式 | 试用中 / 正式许可 / 已过期 |
| 天剩余 | 试用或许可的剩余天数 |
| 客户 | 许可签发对象 |
| 版本 | 许可的版本 |
| 到期时间 | 许可失效日期 |

::: danger 试用到期会锁定管理操作
页面明确提示：「试用到期后管理操作将被锁定，请及时申请并激活正式许可。」

到期后已部署的智能体不会被停掉，但控制台的管理类操作会被拦住。**别等到最后一周才开始走采购流程。**
:::

### 绑定信息

展示用于申请许可的 **vCenter IP**，可一键复制（复制后按钮变「已复制」）。

尚未接入任何资源池时显示「尚未接入资源池」—— 需要先[接入资源池](/console/resource-pools)。

::: warning 更换 vCenter 需要重新申请
说明文字：「正式许可绑定首个接入资源池的 vCenter IP；更换 vCenter 后需重新申请。」

所以多资源池场景下，**先想清楚哪个 vCenter 是"主"再接第一个**。
:::

### 激活步骤

<ol class="ap-steps">
<li>查看上方的绑定 IP。</li>
<li>凭该 IP 向厂商申请许可。</li>
<li>把厂商签发的许可密钥粘贴到下方输入框。</li>
<li>点「激活」，状态变为「正式许可」，提示「许可激活成功」。</li>
</ol>

## 个性化设置

统一管理平台品牌 Logo、登录页样式与版权信息。左侧编辑、右侧**实时预览**；有改动时会提示「有未保存的更改」。

### 基础品牌信息

| 字段 | 出现在哪 |
|---|---|
| 平台名称 | 顶栏品牌名 |
| 平台简称 | 侧栏折叠时显示 |
| 浏览器标题 | 浏览器标签页文字 |
| 登录页副标题 | 登录页的一句话说明 |

### 品牌资源

| 字段 | 说明 |
|---|---|
| Logo | 顶栏与登录页的标识 |
| Favicon | 浏览器标签图标 |
| 登录页图形 | 登录页背景图 |
| 背景遮罩 | 可开关；提升背景图上的文字可读性 |
| 登录卡片位置 | 登录框在页面中的位置 |

::: tip 上传有大小限制
超限会提示「文件大小不能超过 N」。建议 Logo 用 SVG，或压缩过的 PNG（几十 KB 足够）。背景图控制在 500 KB 以内，否则登录页首屏会明显变慢。
:::

### 界面主题

- **品牌主色** —— 影响按钮、链接、强调色
- **界面主题** —— 浅色 / 深色（用户也可以在顶栏自行切换）

### 页脚信息

| 字段 | 说明 |
|---|---|
| 版权信息 | 页脚版权文字 |
| 技术支持 | 支持联系方式文字 |
| 技术支持链接 | 点击跳转的 URL |

::: tip 把内部支持渠道填进去
「技术支持链接」填你们内部的工单系统或值班群链接，比留厂商官网有用得多 —— 用户遇到问题时第一眼看到的就是它。
:::

改完点 **保存**（成功提示「已保存」）；想恢复出厂外观点 **使用默认**。

### 品牌落地的推荐顺序

<ol class="ap-steps">
<li><strong>先定平台名称与浏览器标题</strong> —— 这两项出现频率最高，改完立刻有「这是我们自己的系统」的感觉。</li>
<li><strong>换 Logo 与 Favicon</strong> —— 用 SVG 最省事，深浅两个主题下都要看一眼对比度。</li>
<li><strong>调品牌主色</strong> —— 建议直接用企业 VI 的主色值，别自己调。</li>
<li><strong>换登录页图形</strong> —— 大图注意压缩；文字压不住时打开「背景遮罩」。</li>
<li><strong>最后填页脚</strong> —— 版权信息 + <strong>内部工单系统链接</strong>。</li>
</ol>

::: tip 深浅两个主题都要验
右侧实时预览默认跟随当前主题。改完主色和 Logo 之后，用顶栏的主题开关切到另一个模式再看一遍 —— 浅色下好看的深色 Logo，切到深色主题经常就糊了。
:::

## 许可与品牌的关系

两个页签在一个页面里，但完全独立：

| | 许可管理 | 个性化设置 |
|---|---|---|
| 影响什么 | 平台能不能用 | 平台长什么样 |
| 到期 / 未配 的后果 | 管理操作被锁定 | 只是显示默认外观 |
| 优先级 | 🔴 装完就要确认 | 🟢 有空再弄 |

::: warning 别把「许可还剩多少天」当成不紧急的事
90 天试用听起来很长，但企业采购流程走完往往就要一两个月。装完当天就看一眼到期日，并在日历上提前 30 天设个提醒。
:::

## 关于对话框

顶栏用户菜单里的「关于」展示：

- 平台名称与一句话简介
- **版本号**
- 版权信息

::: tip 报障先看版本号
提工单时把这里的版本号一并附上，能省掉一轮来回确认。
:::

## 常见问题

| 现象 | 处理 |
|---|---|
| 绑定信息显示「尚未接入资源池」 | 先接入一个资源池 |
| 激活失败 | 确认许可密钥完整（首尾无空格）、确认是按当前绑定 IP 签发的 |
| 换了 vCenter 后许可失效 | 按新的 vCenter IP 重新申请 |
| 上传 Logo 报错 | 超过大小限制，压缩后重试 |
| 改了品牌但没生效 | 确认点了「保存」；浏览器强刷一次（Cmd/Ctrl+Shift+R） |
| 试用快到期了 | 立即走申请流程 —— 到期后管理操作会被锁定 |
