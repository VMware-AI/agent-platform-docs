# 平台设置

> 系统配置 → 平台设置 · 需要 <span class="ap-badge admin">admin</span>

管理平台许可与外观个性化配置。页面有两个页签：**许可管理** 与 **个性化设置**。

## 许可管理

平台默认提供 **90 天试用**。正式许可与**首个接入资源池的 vCenter IP** 绑定，凭该 IP 向厂商申请。

### 状态面板

| 字段 | 说明 |
|---|---|
| 模式 | 试用中 / 正式许可 / 已过期 |
| 天剩余 | 试用或许可的剩余天数 |
| 客户 | 许可签发对象 |
| 版本 | 许可的版本 |
| 到期时间 | 许可失效日期 |

::: danger 试用到期会锁定管理操作
到期后管理类操作被锁定，请提前申请并激活正式许可。
:::

### 绑定信息

展示用于申请许可的 **vCenter IP**，可一键复制。尚未接入任何资源池时显示「尚未接入资源池」—— 需先[接入资源池](/console/resource-pools)。

::: warning 更换 vCenter 需要重新申请
许可绑定的是首个接入资源池的 vCenter IP。更换 vCenter 之后原许可失效，需重新申请。
:::

### 激活步骤

<ol class="ap-steps">
<li>查看上方的绑定 IP。</li>
<li>凭该 IP 向厂商申请许可。</li>
<li>把厂商签发的许可密钥粘贴到输入框。</li>
<li>点「激活」，状态变为「正式许可」。</li>
</ol>

## 个性化设置

统一管理平台品牌 Logo、登录页样式与版权信息。左侧编辑、右侧**实时预览**；有未保存的更改时会提示。

### 基础品牌信息

| 字段 | 说明 |
|---|---|
| 平台名称 | 顶部品牌名 |
| 平台简称 | 侧栏折叠时显示 |
| 浏览器标题 | 浏览器标签页文字 |
| 登录页副标题 | 登录页的一句话说明 |

### 品牌资源

| 字段 | 说明 |
|---|---|
| Logo | 顶部与登录页的标识 |
| Favicon | 浏览器标签图标 |
| 登录页图形 | 登录页背景图 |
| 背景遮罩 | 可开关；提升背景图上的文字可读性 |
| 登录卡片位置 | 登录框在页面中的位置 |

::: tip 上传有大小限制
超限时会提示「文件大小不能超过 N」。建议 Logo 用 SVG 或压缩过的 PNG。
:::

### 界面主题

- **品牌主色** —— 影响按钮、链接、强调色
- **界面主题** —— 浅色 / 深色（用户也可以在顶栏自行切换）

### 页脚信息

版权信息、技术支持文字与技术支持链接。

改完点 **保存**；想恢复出厂外观点 **使用默认**。

## 关于对话框

顶栏用户菜单里的「关于」展示平台版本号与版权信息 —— 报障时请附上这里的版本号。
