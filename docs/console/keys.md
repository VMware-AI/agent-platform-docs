# 密钥管理

> 模型调度台 → 密钥管理 · 需要 <span class="ap-badge admin">admin</span>

颁发和管理调用方使用的 API 密钥（虚拟密钥），支持额度与作用域控制。密钥是平台治理的核心抓手 —— **每个智能体绑一把密钥，成本、限流与权限都挂在它上面。**

## 颁发密钥

点 **颁发密钥**：

| 字段 | 说明 |
|---|---|
| 密钥名称 | 平台内唯一。建议与用途对应，如 `agent-研发部-01` |
| 模型网关 | 该密钥归属的网关 |
| 可调用模型 | 选网关后加载可用路由列表；不选 = 全部 |
| 有效时长 | 留空 = 永不过期。支持小时 / 天 / 周 / 月，如 `30d` |
| 消费上限 | 累计花费封顶；达到后调用被拒 |
| 最大并发 | 同时在飞的请求数上限 |
| RPM 限制 / TPM 限制 | 每分钟请求数 / Token 数上限，各自可选模式 |
| 自动轮换 | 开启后按「轮换周期」自动换发新密钥 |
| 标签 | 用于分组与检索 |

::: danger 密钥明文只显示一次
颁发成功后会弹出一次性对话框展示完整密钥（`sk-…`）。**关闭后无法再次查看**，列表里只保留掩码。请立即复制并妥善保存。
:::

## 列表能看到什么

| 列 | 说明 |
|---|---|
| 名称 | 密钥名 |
| 绑定的智能体 | 密钥归属的实例，成本按此归属 |
| 所属模型网关 | 归属网关 |
| 可调用模型 | 作用域内的路由，超出时显示「再显示 N 个」 |
| 密钥 | 掩码形式 |
| 状态 | 启用 / 禁用 |
| 过期时间 | 到期后自动失效 |
| **消费进度** | 已用 / 上限，直观看出快超预算的密钥 |
| 时间信息 | 最近活动 · 创建 · 更新 |

## 行内操作

| 操作 | 说明 |
|---|---|
| 查看 | 只读详情，分四组：基本信息 · 治理参数 · 速率限制 · 路由与标签 |
| 编辑 | 改作用域、限流、预算、过期时间 |
| 克隆 | 以现有密钥为模板颁发新密钥，适合批量发同规格密钥 |
| 启用 / 禁用 | 立即生效；禁用后该密钥的调用全部 401 |
| 复制令牌掩码 / 复制智能体 ID | 便于对账与排障 |
| 删除 | 二次确认，不可撤销 |
| 清理密钥 | 批量清除 N 天前所有已吊销的令牌 |

批量操作：**批量启用 / 禁用 / 删除**。

## 密钥与智能体的绑定

绑定发生在**部署智能体**时 —— 部署向导的实例清单里每台机器都要选一个「网关密钥绑定」。绑定之后：

- 该 VM 内的 agent 用这把密钥调用网关
- 计量中心可以按智能体维度归集成本
- 密钥被禁用 / 超预算时，只影响这一台智能体

::: tip 一机一密钥
建议不要多台智能体共用一把密钥 —— 共用会让成本无法归属到具体的人或实例，出问题时也无法精确止血。
:::

## 治理建议

| 场景 | 配置 |
|---|---|
| 试点阶段 | 不设预算上限、不设过期，先跑通 |
| 按部门发放 | 用标签标注部门；各设消费上限；月度对账看[计量中心](/observability/metering)按部门维度 |
| 外包 / 临时人员 | 设 30d 过期 + 较低的消费上限 + 限定可调用模型 |
| 高敏场景 | 开启自动轮换，缩短轮换周期 |
| 人员离职 | 立即**禁用**（而不是删除）—— 保留历史账单与审计关联 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 智能体调用返回 401 | 密钥被禁用 / 已过期 / 超出消费上限；或请求的模型不在作用域内 |
| 调用返回 429 | 触发 RPM / TPM / 最大并发限制，调高限额或分散流量 |
| 忘记密钥明文 | 无法找回。删除旧密钥，重新颁发一把并更新到 VM 里 |
| 消费进度不动 | 该密钥未被实际使用，或模型未配置单价（成本算不出来） |
