# 总览仪表盘

登录后的首页，一屏回答四个问题：**平台健不健康、智能体在不在跑、调用质量如何、这个月花了多少钱。**

页面右上角提供**刷新**与**自动刷新**开关，并显示最新刷新时间。

## 顶部 KPI 卡

| 卡片 | 含义 | 点击行为 |
|---|---|---|
| 平台健康度 | 正常 / 存在警告 / 部分异常 / 严重异常，附严重与警告计数 | — |
| 活跃智能体 | 运行中实例数 / 智能体池总数 | 跳智能体实例 |
| 接入模型 | 健康模型数 / 模型总数 | 跳模型管理 |
| 总请求量 | 统计窗内的调用总数（已剔除重复） | 跳请求日志 |
| P95 响应时间 | 95 分位延迟，附平均延迟 | 跳实时监控 |
| 本月费用 | 当月累计花费与预计月底费用 | 跳计量中心 |

## 主要区块

### 平台组件健康

后端服务、网关、数据库等组件的实时状态，附平台最近检查时间。任一组件异常时，顶部健康度会同步下降。

### 实例状态分布与健康度趋势

智能体实例按**运行中 / 已停止 / 异常 / 已回收**分布的环图，以及健康度随时间的趋势线。

::: tip 「已回收」不是错误
实例被删除后转为已回收状态，记录保留用于审计与历史账单归属，不占用 vCenter 资源。
:::

### 调用质量

统计窗内的成功率、错误率与延迟走势。异常升高时先去[请求日志](/observability/request-log)按状态码筛选定位。

### 最近智能体运行

最近的调用记录表：智能体、模型、Token、延迟、状态、时间。点「查看全部请求日志」进入完整视图。

### 本月用量摘要

- 当月累计花费与**预计月底费用**
- 较上月变化
- **最高消耗智能体**

预测口径可在[计量设置](/observability/metering-settings)里切换（当月日均线性 / 最近 7 天日均 / 不显示）。

### 异常与待处理事项

聚合当前需要人工处理的项：异常实例、熔断模型、即将过期的密钥、超预算告警等。无事项时显示「当前暂无待处理异常」。

### 快捷入口

一行直达：智能体列表 · 模型管理 · 实时监控 · 请求日志 · 计量中心 · 审计日志。

## 谁能看到这一页

所有已登录用户都能进入总览，但**卡片内容按权限裁剪** —— 例如 `user` 角色看不到全平台费用与全量实例统计。观测岗 `read_only` 可以看全部只读指标。
