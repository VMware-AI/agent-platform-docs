# 智能体实例

> 智能体中心 → 智能体实例

统一管理已部署的智能体实例，支持筛选、批量操作与导出。这是日常运维停留时间最长的一页。

## 列表

| 列 | 说明 |
|---|---|
| 名称 | 支持搜索 |
| 智能体类型 | OpenClaw / Hermes / 小怪 / QCoder / OpenCode，可筛选 |
| 状态 | 运行中 / 已停止 / 已回收 / 部署中 / 异常，可筛选 |
| 密钥名称 | 绑定的虚拟密钥，支持搜索 |
| 运行账户 | VM 内的 OS 账户，支持搜索 |
| 创建时间 / 更新时间 | 排序字段 |

工具栏：**刷新**、**导出列表**、**批量操作**。

## 状态含义

| 状态 | 含义 |
|---|---|
| 部署中 | 克隆 / 开机 / 等待注册中 |
| 运行中 | 心跳正常 |
| 已停止 | VM 已关机 |
| 异常 | 心跳超时或部署失败 |
| 已回收 | 已删除释放；记录保留用于审计与历史账单 |

## 行内操作

| 操作 | 说明 |
|---|---|
| **访问信息** | 打开凭据面板：密钥名称、OS 账户、登录密码、SSH 连接命令、IP 地址，支持一键复制全部 |
| **配置** | 打开配置面板，改虚拟机资源、网络、vApp 参数（见下） |
| 启动 / 停止 / 重启 | VM 电源操作 |
| 密码更新 | 触发凭据更新流程 |
| 版本更新 | 下发升级命令，VM 内 agent-manager 在下次心跳时拉取安装 |
| 安装 Skill | 从离线技能库挑包安装到这台机器 |
| 删除 | 释放 VM，实例转「已回收」 |
| 彻底删除 | 连同记录一并清除 |
| 复制密钥 | 复制绑定的密钥名 |

批量操作：**批量启动 / 停止 / 更新 / 删除 / 彻底删除**。完成后会汇总「成功 N 个，失败 M 个」。

::: tip 先选中再批量
未选中任何实例时批量按钮是禁用的，提示「请先选择智能体」。
:::

## 访问信息面板

发给使用者的就是这一屏的内容：

| 字段 | 说明 |
|---|---|
| 密钥信息 | 绑定的网关密钥名称 |
| OS 账户 | VM 登录用户名 |
| 登录密码 | 部署时设定的密码 |
| SSH 连接 | 可直接复制粘贴的完整命令 |
| IP 地址 | VM 的实际地址 |

点 **一键复制全部凭据** 把整段发给使用者。

::: warning 密码由部署时设定，平台不存明文
如遗忘，需通过 vCenter Console 重置，或让使用者在 [VM 自服务管理台](/agent-vm/webadmin) 修改。
:::

## 配置面板

点「配置」打开，分六段。🔒 标记的字段为只读。

### 基础信息

名称、类型、来源模板、资源池等元数据。

### 虚拟机资源配置

| 字段 | 约束 |
|---|---|
| CPU 核数 | 1 – 上限；**运行中仅支持扩容** |
| 内存（GB） | 1 – 上限；运行中仅支持扩容 |
| 磁盘（GB） | 下限 – 上限；**磁盘只支持扩容**，任何状态下都不能缩 |

::: tip 想缩配就先停机
运行中实例只允许扩容。需要缩减 CPU / 内存时，先停止实例，停止状态下可自由调整规格。
:::

### 网络配置

切换**端口组**。切换会临时断开虚拟机网络，建议在业务低峰时段操作。

### vApp 部署参数

模版族、模版版本、资源池、运行账户，以及**自定义 OVF 属性**（可增删键值对）。

### 网络访问信息

跳转到访问信息弹窗，查看 SSH 命令与登录凭据。

### 快捷运维操作

密码更新 · 密钥轮换 · 重启实例 · 停止实例 · 保存配置。

### 保存前的变更确认

点「保存配置」后会弹出**确认配置变更**对话框，逐项列出「字段 / 变更前 / 变更后」，确认后才在 vCenter 上同步执行。

::: warning 异常状态实例不支持配置
状态为「异常」的实例暂不支持打开配置面板 —— 先恢复心跳或删除重建。
:::

## 智能体详情页

点实例名称进入详情，展示：名称、类型、状态、VM 端点、运行账号、网关密钥、来源模板、资源池、创建 / 更新时间。

## 常见问题

| 现象 | 处理 |
|---|---|
| 实例转「异常」 | VM 是否关机 / 网络中断；VM 内 `systemctl status agent-manager` |
| 访问信息取不到 | 实例需处于运行中且已上报 IP |
| 配置保存失败 | 看差异对话框里的字段；常见为 vCenter 侧资源不足或权限不够 |
| 删了还在列表里 | 删除后转「已回收」保留记录，用「彻底删除」清除 |
