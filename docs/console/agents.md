# 智能体实例

> 智能体中心 → 智能体实例

统一管理已部署的智能体实例，支持筛选、批量操作与导出。这是日常运维停留时间最长的一页。

## 列表

| 列 | 说明 |
|---|---|
| 名称 | 支持搜索 |
| 智能体类型 | OpenClaw / Hermes / 小怪 / QCoder / OpenCode，可筛选 |
| 状态 | 见下方状态表，可筛选 |
| 密钥名称 | 绑定的虚拟密钥，支持搜索 |
| 运行账户 | VM 内的 OS 账户，支持搜索 |
| 创建时间 / 更新时间 | 排序字段 |

排序支持：名称 · 类型 · 状态 · 密钥名 · 运行账户 · 创建时间 · 更新时间，升序 / 降序。

工具栏：**刷新**、**导出列表**、**批量操作**。底部显示 `显示 x-y 条，共 N 条`，可调每页条数。

## 状态

| 状态 | 后端枚举 | 含义 | 能做什么 |
|---|---|---|---|
| 部署中 | `provisioning` | 克隆 / 开机 / 等待注册中 | 等待，不要操作 |
| 运行中 | `running` | 心跳正常 | 全部操作 |
| 已停止 | `stopped` | VM 已关机 | 启动、删除、**自由调整资源规格** |
| 异常 | `exception` | 心跳超时或部署失败 | 启停、删除；**不支持配置** |
| 已回收 | — | 已删除释放，记录保留 | 仅查看、彻底删除 |

::: tip 「已回收」不是错误
实例删除后转已回收：vCenter 侧的 VM 已释放，平台侧保留记录，用于审计追溯与历史账单归属。要彻底清掉用「彻底删除」。
:::

## 行内操作

| 操作 | 说明 |
|---|---|
| **访问信息** | 打开凭据面板（详见下节） |
| **配置** | 打开配置面板，改资源 / 网络 / vApp 参数 |
| 启动 / 停止 / 重启 | VM 电源操作 |
| **密码更新** | 触发凭据更新流程（对应后端的 OS 口令轮换） |
| **版本更新** | 下发升级命令，VM 内 agent-manager 下次心跳时拉取安装 |
| **安装 Skill** | 从离线技能库挑包安装到这台机器 |
| 复制密钥 | 复制绑定的密钥名 |
| **删除** | 释放 VM，实例转「已回收」 |
| **彻底删除** | 连同记录一并清除 |

批量：**批量启动 / 停止 / 更新 / 删除 / 彻底删除**，完成后汇总「成功 N 个，失败 M 个」。未选中时批量按钮禁用并提示「请先选择智能体」。

::: warning 批量删除前先导出
「导出列表」会把当前筛选结果导出。批量回收一批实例之前先导一份，留个底 —— 谁在用哪台、绑了哪把密钥，回收后再想查就得翻审计日志了。
:::

## 版本更新

单台或批量选中后点「版本更新」：

| 字段 | 约束 |
|---|---|
| 目标版本 | **仅允许字母数字与 `.` `_` `-`**，不含路径分隔符、空格或 shell 元字符 |

提示语会明确告知这是异步的：

- 单台：「将为『xxx』下发升级命令，VM 内 agent-manager 会在下次心跳时拉取安装。」
- 批量：「将为选中的 N 个智能体下发同一升级命令（各自下次心跳时执行）。」

::: tip 版本号是自由文本
控制台不提供版本下拉 —— 后端只校验**格式**，不校验该版本在包仓库里是否真的存在。下发前先确认内网包仓库有 `<包名>-<版本>.tar.gz`，否则 VM 侧会拉取失败。

VM 内的[自服务管理台](/agent-vm/webadmin)反而能列出「服务端可拉取版本」，不确定版本号时可以先去那里看一眼。
:::

详见 [升级与回滚](/agent-vm/upgrade)。

## 密码更新 vs 密钥轮换

「快捷运维操作」里这两个名字很像，做的事不一样：

| 操作 | 换的是什么 | 影响 |
|---|---|---|
| **密码更新** | VM 的 **OS 登录口令** | 使用者的 SSH 密码变了，需要重新告知 |
| **密钥轮换** | VM **管理台**的凭据 | 使用者访问 `/manage/` 的密码变了 |

::: tip VM 密码默认 30 天自动轮换
平台会在心跳时检查 VM 管理台密码的上次轮换时间，**超过 30 天**就自动排队一条轮换命令（同一时刻只允许一条在飞）。

这意味着使用者会周期性地被要求改密 —— 提前告知他们这是正常策略，免得当成故障来报。使用者自己在[管理台](/agent-vm/webadmin)改密时，OS 和管理台两边是同步更新的。
:::

## 访问信息面板

发给使用者的就是这一屏：

| 字段 | 说明 |
|---|---|
| 密钥信息 | 绑定的网关密钥名称 |
| OS 账户 | VM 登录用户名 |
| 登录密码 | 部署时设定的密码 |
| SSH 连接 | 可直接复制粘贴的完整命令 |
| IP 地址 | VM 的实际地址 |

点 **一键复制全部凭据** 得到一段可直接发出去的文本。各字段也可单独复制。

::: warning 拿不到访问信息
实例需处于运行中且已上报 IP。部署中 / 异常状态可能取不到凭据，会提示「无法获取虚拟机凭据」。
:::

## 配置面板

点「配置」打开，分六段。**🔒 标记的字段为只读**，标题下有说明「查看与修改智能体部署参数」。

### 基础信息

名称、类型、来源模板、资源池等元数据。

### 虚拟机资源配置

| 字段 | 约束 |
|---|---|
| CPU 核数 | 1 – 上限；**运行中仅支持扩容** |
| 内存（GB） | 1 – 上限；运行中仅支持扩容 |
| 磁盘（GB） | 下限 – 上限；**磁盘任何状态下都只能扩容** |

界面会显示当前值与允许范围（`当前 4 核，范围 1-16`），并按状态给出不同提示：

- 运行中：「运行中实例仅支持扩容，缩减需先停止实例」
- 已停止：「已停止实例可自由调整资源规格」

::: tip 想缩配就先停机
唯一例外是磁盘 —— vSphere 本身不支持在线缩盘，停机也不行。磁盘只能扩。
:::

### 网络配置

切换**端口组**，下拉来自资源池同步下来的网络清单。

::: warning 切换端口组会断网
界面明确提示「切换端口组将临时断开虚拟机网络，建议业务低峰时段操作」。切完之后如果 VM 用的是静态 IP，可能还需要进 VM 改网卡配置。
:::

### vApp 部署参数

模版族、模版版本、资源池、运行账户，以及**自定义 OVF 属性** —— 可以增删键值对（`+ 添加属性` / `移除`）。

### 网络访问信息

跳转到访问信息弹窗。

### 快捷运维操作

| 操作 | 说明 |
|---|---|
| 密码更新 | 更新 OS 登录口令 |
| 密钥轮换 | 轮换管理台 / 凭据 |
| 重启实例 | 仅运行中实例可用 |
| 停止实例 | 仅运行中实例可用 |
| 保存配置 | 把资源 / 网络 / vApp 的改动同步到 vCenter |

### 保存前的变更确认

点「保存配置」后弹出**确认配置变更**对话框，逐项列出「字段 / 变更前 / 变更后」（CPU 核数、内存、磁盘、端口组、运行账户），确认后才在 vCenter 上执行。无变更时显示「无变更项」。

::: warning 异常状态实例不支持配置
状态为「异常」的实例打不开配置面板，提示「异常状态实例暂不支持配置」—— 先恢复心跳，或直接删除重建。
:::

## 智能体详情页

点实例名称进入，展示：名称、类型、状态、VM 端点、运行账号、网关密钥、来源模板、资源池、创建 / 更新时间。顶部有「返回智能体实例」。

## 快照

平台后端支持对实例做**快照**与**回滚快照**，相关动作会记入[审计日志](/observability/audit-log)（动作：创建快照 / 回滚快照）。

::: tip 当前版本控制台没有快照按钮
v0.0.1 的控制台界面上没有暴露快照入口。需要快照能力时，直接在 vCenter 侧对目标 VM 操作 —— 智能体 VM 是完全独立的清单对象，vSphere 的快照 / 回滚对它完全适用。
:::

## 运维动作速查

| 我想…… | 去哪 |
|---|---|
| 给使用者发凭据 | 访问信息 → 一键复制全部凭据 |
| 加内存 / 加盘 | 配置 → 虚拟机资源配置（运行中只能扩） |
| 缩 CPU / 内存 | 先停止实例，再改 |
| 换网段 | 配置 → 网络配置 → 换端口组（会断网） |
| 升级 agent 版本 | 版本更新（异步，下次心跳生效） |
| 装个 Skill | 安装 Skill，或去[技能管理](/console/skills) |
| 用户忘了密码 | 密码更新，或让其走 [VM 管理台](/agent-vm/webadmin) |
| 人走了要回收 | 先禁用其绑定的[密钥](/console/keys)，再删除实例 |
| 查这台机器花了多少钱 | [计量中心](/observability/metering)按智能体下钻 |
| 查这台机器的调用记录 | [请求日志](/observability/request-log)按智能体 ID 筛 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 实例转「异常」 | VM 是否关机 / 网络中断；VM 内 `systemctl status agent-manager`、`journalctl -u agent-manager -f` |
| 访问信息取不到 | 实例需运行中且已上报 IP |
| 配置保存失败 | 看变更确认里的字段；常见为 vCenter 资源不足或权限不够 |
| 删了还在列表里 | 删除后转「已回收」保留记录，用「彻底删除」清除 |
| 某操作提示「暂未开放」 | 该功能后端接口开发中，当前版本不可用 |
| 批量操作部分失败 | 结果汇总里有成功 / 失败计数；失败的逐台看状态再重试 |
