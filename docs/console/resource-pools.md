# 资源池接入

> 系统配置 → 资源池接入 · 需要 <span class="ap-badge admin">admin</span>

**资源池**就是一个已接入的 vCenter，是智能体运行的物理底座。没有它就无法部署任何智能体。

## 接入一个 vCenter

点右上角 **接入资源池**，填写：

| 字段 | 说明 |
|---|---|
| 资源池名称 | 平台内的显示名，建议与 vCenter 的用途对应，如 `vCenter-生产-北京` |
| VC 地址 | vCenter 的 FQDN 或 IP |
| vCenter 账号 | 具备克隆、改配置、开关机、删除 VM 与读内容库权限的账号 |
| vCenter 密码 | 后端加密入库；编辑时留空表示不修改已保存的凭据 |
| 跳过 TLS 验证 | 自签名 / 内网 CA 的 vCenter 勾选；**生产环境建议保持验证** |
| 内容库 | 存放智能体 OVA 模板的 Content Library |

<ol class="ap-steps">
<li>填完地址与账号口令，先点 <strong>测试连接</strong>。</li>
<li>连接成功后会显示探测结果（vSphere 版本 · 内容库数量），并加载「内容库」下拉。</li>
<li>选择内容库，点 <strong>保存</strong>。</li>
</ol>

::: warning 必须先测试连接
「内容库」下拉在测试连接成功之前是空的 —— 它的选项来自那次探测的结果。
:::

## 同步与资产

保存后平台会自动同步该 vCenter 的清单。列表页的**同步状态**列显示「已同步 / 未同步 / xx 前已同步」。也可以随时点行内的 **立即同步** 手动触发。

同步下来的资产按类别归档，点 **资产 → 查看** 打开：

| 分组 | 用途 |
|---|---|
| 集群 | 放置目标 |
| 主机 | 放置目标 |
| 资源池 | 部署时的「vSphere 放置资源池」 |
| 数据存储 | 部署时的「目标数据存储」 |
| 网络 | 部署时的「目标端口组」 |
| VM 文件夹 | 实例归档位置 |
| 存储策略 | vSAN 存储策略 |

::: tip 部署页下拉为空？
先回这里点「立即同步」。部署对话框里的资源池 / 端口组 / 数据存储选项全部来自这份同步数据；尚未同步时「查看资产」按钮也是禁用的。
:::

## 列表页能做什么

| 列 / 操作 | 说明 |
|---|---|
| 资源池名称 · VC 地址 | 支持搜索框按名称或 VC 地址过滤 |
| 同步状态 | 已连接 / 未连接、已同步 / 未同步，可按状态筛选 |
| 内容库 | 当前绑定的内容库 |
| 创建时间 / 更新时间 | 排序字段 |
| 管理 | 进入资源池详情 |
| 立即同步 | 手动触发一次清单同步 |
| 编辑 | 改名称、地址、凭据、内容库（密码留空 = 不改） |
| 删除 | 二次确认；最终确认需要**输入资源池名称** |

## 删除的影响

::: danger 删除前先确认没有实例在用
删除资源池会切断该 vCenter 的接入，其上已部署的智能体实例将失去管理通道。二次确认要求手工输入资源池名称，就是为了防误删。
:::

另外，**正式许可与首个接入资源池的 vCenter IP 绑定**。更换 vCenter 后需要重新向厂商申请许可，详见 [平台设置](/console/settings)。

## 常见问题

| 现象 | 处理 |
|---|---|
| 测试连接失败 | 平台主机能否访问 vCenter 443；账号口令是否正确；自签证书需勾选跳过 TLS 验证 |
| 内容库下拉为空 | 未测试连接，或该 vCenter 上确实没有 Content Library |
| 资产为空 | 尚未同步，点「立即同步」后稍等再看 |
| 部署时报权限错误 | vCenter 账号缺少克隆 / 改 vApp 属性 / 开关机 / 删除 VM 的权限 |
