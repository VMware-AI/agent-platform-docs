# 资源池接入

> 系统配置 → 资源池接入 · 需要 <span class="ap-badge admin">admin</span>

**资源池**就是一个已接入的 vCenter，是智能体运行的物理底座。没有它无法部署任何智能体，正式许可也绑定在首个接入资源池的 vCenter IP 上。

## 接入一个 vCenter

点右上角 **接入资源池**：

| 字段 | 说明 |
|---|---|
| 资源池名称 | 平台内显示名，建议体现用途与环境，如 `vCenter-生产-北京` |
| VC 地址 | vCenter 的 FQDN 或 IP |
| vCenter 账号 | 见下方权限清单 |
| vCenter 密码 | 后端加密入库；**编辑时留空 = 不修改已保存的凭据** |
| 跳过 TLS 验证 | 自签名 / 内网 CA 的 vCenter 勾选；生产环境建议保持验证 |
| 内容库 | 存放智能体 OVA 模板的 Content Library |

<ol class="ap-steps">
<li>填地址与账号口令，先点 <strong>测试连接</strong>。</li>
<li>成功后会显示探测结果 —— <code>vSphere &lt;版本&gt; · N 个内容库</code>，并据此加载「内容库」下拉。</li>
<li>选内容库，点 <strong>保存</strong>。</li>
</ol>

::: warning 必须先测试连接
「内容库」下拉的选项来自那次探测的结果。没测过连接，下拉就是空的，会提示「请先测试连接以加载内容库列表」。
:::

### vCenter 账号需要的权限

| 操作 | 用到的权限 |
|---|---|
| 读清单（集群 / 主机 / 数据存储 / 网络 / 文件夹 / 存储策略） | 只读 |
| 从内容库部署 | 内容库项读取、部署 OVF 模板 |
| 克隆虚拟机 | 虚拟机 → 置备 → 克隆 |
| 注入 guestinfo / vApp 属性 | 虚拟机 → 配置 → 高级配置、修改设备设置 |
| 开关机、重启 | 虚拟机 → 交互 |
| 调整 CPU / 内存 / 磁盘 | 虚拟机 → 配置 |
| 删除虚拟机 | 虚拟机 → 清单 → 移除 |
| 快照与回滚 | 虚拟机 → 快照管理 |

::: tip 最小权限
不建议直接用 administrator。建一个专用角色按上表授权，作用域限定在承载智能体的集群 / 文件夹上，出问题时爆炸半径可控。
:::

## 同步与资产

保存后平台会自动同步该 vCenter 的清单，之后按 `POOL_SYNC_INTERVAL_SECONDS` 周期刷新，并带重试与断路器保护（相关调优项见[环境变量](/reference/env)）。

### 同步状态

| 状态 | 后端枚举 | 含义 |
|---|---|---|
| 已同步 | `SYNCED` | 最近一次同步成功 |
| 同步中 | `SYNCING` | 正在拉取 |
| 部分同步 | `PARTIAL` | 部分对象拉取失败 |
| 失败 | `FAILED` | 同步失败，多为凭据或网络问题 |
| 未同步 | `NEVER` | 从未成功同步过 |

列表会显示「xx 前已同步」，也可以随时点行内的 **立即同步** 手动触发。

### 同步下来的资产

点 **资产 → 查看** 打开，按 vCenter 的层级组织：

```
数据中心 DataCenter
├─ 集群 Cluster
│   ├─ ESXi 主机
│   └─ vSphere 资源池      ← 部署时的「vSphere 放置资源池」
├─ 数据存储 Datastore      ← 部署时的「目标数据存储」
├─ 网络 / 端口组           ← 部署时的「目标端口组」
├─ VM 文件夹
└─ 存储策略
```

::: tip 部署页下拉为空？先来这里
部署对话框里的 vSphere 资源池 / 端口组 / 数据存储选项**全部来自这份同步数据**。尚未同步时「查看资产」按钮也是禁用的，提示「资源池尚未同步，无法查看资产」。
:::

## 列表页

| 列 / 操作 | 说明 |
|---|---|
| 资源池名称 · VC 地址 | 搜索框支持按名称或 VC 地址过滤 |
| 同步状态 | 可按状态筛选 |
| 内容库 | 当前绑定的内容库 |
| 资产 | 「查看」打开资产抽屉 |
| 创建 / 更新时间 | 排序字段 |
| 管理 | 进入资源池详情 |
| 立即同步 | 手动触发一次清单同步 |
| 编辑 | 改名称、地址、凭据、内容库（密码留空 = 不改） |
| 删除 | 二次确认；最终确认需**输入资源池名称** |

## 删除的影响

::: danger 删除前先确认没有实例在用
删除资源池会切断该 vCenter 的接入，其上已部署的智能体实例将失去管理通道（无法启停、改配、回收）。二次确认要求手工输入资源池名称，就是为了防误删。
:::

另外 —— **正式许可与首个接入资源池的 vCenter IP 绑定**。删掉再换一个 vCenter，需要重新向厂商申请许可，见[平台设置](/console/settings)。

## 多资源池

平台支持接入多个 vCenter。常见分法：

| 分法 | 说明 |
|---|---|
| 按环境 | 生产 / 测试各一个，模板与实例天然隔离 |
| 按地域 | 北京 / 上海各一个，就近交付降低延迟 |
| 按安全域 | 研发网 / 办公网各一个，配合 NSX 微分段 |

部署时逐台选目标资源池，模板族也绑定在具体的资源池 + 内容库上。

::: warning 许可只认第一个
多资源池场景下，许可仍绑定**首个接入**的那个 vCenter 的 IP。规划时先想清楚哪个是"主"。
:::

## 常见问题

| 现象 | 处理 |
|---|---|
| 测试连接失败 | 平台主机能否访问 vCenter 443（`curl -k https://<vc>/`）；账号口令是否正确；自签证书需勾选跳过 TLS 验证 |
| 连接成功但内容库下拉为空 | 该 vCenter 上确实没有 Content Library，或账号没有内容库读取权限 |
| 同步状态一直「部分同步」 | 账号对部分对象没有读权限；或某个数据中心不可达。看资产里缺了哪一类，对照权限表补 |
| 同步状态「失败」 | 凭据过期或网络中断；编辑资源池重填密码后再同步 |
| 资产是空的 | 尚未同步，点「立即同步」后稍等 |
| 部署时报权限错误 | 对照上方权限清单补 vCenter 角色权限 |
| 编辑时不想改密码 | 密码留空即可，不会覆盖已保存的凭据 |
