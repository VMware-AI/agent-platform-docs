# 部署智能体

> 智能体市场 → 卡片上的「部署智能体」 · 需要 <span class="ap-badge admin">admin</span>

部署向导把「一台或一批智能体虚拟机」拆成四段：**基础运行环境 → 全局安全与认证 → 部署模式与网络 → 实例配置清单**。前三段是所有实例共享的，最后一段逐台确定。

## 一、基础运行环境

所有实例共享的底层 IaaS 资源配置。

| 字段 | 说明 |
|---|---|
| 选择版本 | 模板族下的具体版本，默认最新 |
| vSphere 放置资源池 | VM 放在哪个 vSphere 资源池。留空 = 继承源模板所在池 |
| 目标端口组 | VM 网卡接哪个端口组。留空 = 继承源模板网卡 |
| 目标数据存储 | 默认 `vsanDatastore` |
| 克隆模式 | **全量克隆** 或 **即时克隆** |

### 全量克隆 vs 即时克隆

| | 全量克隆 | 即时克隆 |
|---|---|---|
| 速度 | 分钟级 | **秒级** |
| 需要父虚拟机 | 否 | **是** |
| 后续生命周期 | 完全独立 | 完全独立 |
| 适用 | 少量、常规部署 | 大批量快速交付 |

选择即时克隆后需要指定父虚拟机，有两条路径：

- **选择已有父虚拟机** —— 从下拉里挑
- **创建新父虚拟机** —— 填名称与静态 IP，可添加多个（大批量时用多个父机分摊）

::: tip 即时克隆不影响独立性
克隆出来的 VM 是完全独立的 vCenter 清单对象，可以像常规虚拟机一样管理。即时克隆只影响**创建速度**，不影响后续生命周期与数据持久性。
:::

## 二、全局安全与认证

所有实例统一的 Cloud-Init / vApp 系统凭据。

| 字段 | 说明 |
|---|---|
| 密码 / 确认密码 | VM 的 OS 登录密码，两次一致 |
| SSH 公钥（可选） | 注入到 VM，便于免密登录 |

::: danger 平台不存储明文密码
这里设置的密码经 guestinfo 注入 VM，平台侧**不保存明文**。遗忘只能通过 vCenter Console 重置，或让使用者在 [VM 自服务管理台](/agent-vm/webadmin) 自行修改。发放给使用者后建议要求其立即改密。
:::

## 三、部署模式与网络策略

### 部署模式

- **单台部署** —— 填一台的名称与网络
- **批量部署** —— 填名称前缀、数量、起始 IP，点「生成清单」自动展开

### 网络策略

| 模式 | 需要填 |
|---|---|
| DHCP | 无 |
| 静态 IP | 起始 IP、子网掩码、网关、DNS（逗号分隔多个） |

批量 + 静态 IP 时，从「起始 IP」开始按数量顺序递增分配。

::: warning 静态 IP 冲突是部署卡住的头号原因
生成清单后请核对每台的 IP 是否与现网冲突。IP 冲突的 VM 会开机成功但拿不到网络，实例将长时间停在「部署中」直至转「异常」。
:::

## 四、实例配置清单

生成的表格逐行确认：

| 列 | 说明 |
|---|---|
| 主机名 | 由名称前缀 + 序号生成，可逐行改 |
| IP 地址 | 静态模式下按起始 IP 递增；DHCP 模式为空 |
| 密钥绑定 | **每台选一个虚拟密钥** |

::: tip 一机一密钥
建议每台实例绑定独立密钥，这样计量中心能按智能体归集成本，出问题也能单独禁用止血。密钥不够就先去[密钥管理](/console/keys)批量克隆几把。
:::

确认无误后点 **部署**。

## 部署过程中发生了什么

```
控制台 ──▶ backend ──(govmomi)──▶ vCenter
   ① clone -on=false（从内容库 OVA 模板）
   ② 注入 guestinfo（gzip + base64）：OS 凭据、网关地址、虚拟密钥、知识包授权列表
   ③ power on
   ④ 等待 VM 上报 IP
   ⑤ 任一步失败 → vm.destroy 回滚，不留半成品
VM 侧：cloud-init → agent-manager enroll 注册 → 周期心跳
控制台：状态「部署中」→「运行中」
```

单台通常 **5–10 分钟**完成。批量部署各实例独立推进，部分失败不影响其余。

## 部署后

到[智能体实例](/console/agents)列表：

1. 确认状态为「运行中」
2. 点 **访问信息**，把 IP、SSH 命令、OS 账户与密码发给使用者
3. 需要的话在[技能管理](/console/skills)里给这台机器安装 Skill

## 常见问题

| 现象 | 处理 |
|---|---|
| 下拉（资源池 / 端口组 / 数据存储）为空 | 资源池尚未同步资产，回[资源池接入](/console/resource-pools)点「立即同步」 |
| 「网关密钥绑定」为空 | 还没颁发虚拟密钥 |
| 部署立即失败 | 查审计日志的失败原因：vCenter 权限不足、名称冲突、数据存储空间不足 |
| 长时间「部署中」 | ① VM 是否拿到 IP（静态 IP 配错）② VM 能否出站访问控制面 443 |
| 批量部署部分失败 | 失败的实例删除后重试即可，成功的不受影响 |
