# 智能体配置与知识包

> 智能体中心 → 智能体配置 · 需要 <span class="ap-badge admin">admin</span>

管理智能体配置及其挂载的 **OKF 知识包**。知识包会在部署时注入智能体所在的虚拟机，让 agent 开箱就带着企业自己的资料。

::: warning v0.0.1 侧边栏未暴露入口
这一页在 v0.0.1 的左侧导航里被隐藏了，但功能是完整的，可以直接访问 `/agents/config`。后续版本会重新放回「智能体中心」分组下。

如果你暂时不需要给 agent 挂知识包，可以跳过整页。
:::

## 知识包是什么

一个**离线知识资料包**，随心跳同步到智能体 VM 的知识根目录。

```
控制台挂载知识包到「智能体配置」
        │
部署时把授权列表写进 guestinfo
        │
VM 内 agent-manager 每次心跳同步：
   ① 按授权列表拉取
   ② sha256 三重校验
   ③ 安全解压（防路径穿越）
   ④ 原子切换到知识根目录
   ⑤ 写入本地 state
```

::: tip 它不是 RAG
知识包是**本地文件分发**，不是向量索引。平台负责把资料安全、完整地送到 VM 上；怎么用（喂进 prompt、建索引、还是当参考文档）由 agent 自己决定。
:::

::: tip 同步失败不会影响心跳
知识包同步是 **best-effort** 的：拉取失败、校验不过、解压异常，都会降级跳过并记日志，**绝不破坏心跳**。所以你不会因为一个坏掉的知识包而失去对整台机器的管理能力。
:::

## 页面结构

左侧是**配置列表**，右侧是**配置详情**。

### 配置列表

| 列 | 说明 |
|---|---|
| 配置名称 | 支持搜索 |
| 最新版本 | 该配置的版本 |
| 智能体类型 | 可按类型筛选 |
| 创建时间 / 更新时间 | 排序字段 |

带「默认」徽标的是该类型的默认配置。工具栏：刷新、批量操作、清空筛选。

### 配置详情

选中左侧某个配置后，右侧展示：

| 字段 | 说明 |
|---|---|
| 智能体类型 | 该配置适用的 agent 类型 |
| 是否默认 | 是 / 否 |
| 制品 ID | 关联的制品标识 |
| 创建时间 / 更新时间 | 元数据 |
| **已挂载知识包** | 当前挂了哪些包；未挂时显示「尚未挂载任何知识包」 |

未选中任何配置时提示「请选择左侧的一个配置以查看详情」。

## 挂载知识包

点详情区的 **编辑知识包** 打开对话框：

<ol class="ap-steps">
<li>对话框加载可用知识包列表（「正在加载知识包…」）。</li>
<li>勾选要挂的包，底部显示「已选 N 个知识包」。</li>
<li>点<strong>保存</strong>。</li>
</ol>

没有可用包时显示「暂无可用知识包」—— 说明平台里还没有 `knowledge` 类型的制品。

::: warning 挂载只对「之后部署的实例」自动生效
知识包的授权列表是在**部署时**写进 guestinfo 的。给配置新挂一个包，已经在跑的实例要等它下一次心跳同步（同步逻辑会按当前授权列表拉取），而**新增授权**是否对存量实例生效，取决于该实例部署时下发的列表。

稳妥做法：先把知识包挂好，再部署实例。
:::

## 制品（Artifact）

知识包属于平台的**制品**体系。制品有四种类型：

| 类型 | 用途 |
|---|---|
| `knowledge` | 知识包 —— 本页挂载的就是它 |
| `package` | 安装包 |
| `script` | 脚本 |
| `config` | 配置文件 |

每个制品带：名称、版本、URI、sha256、元数据。**sha256 是知识包三重校验的依据之一**，入库时就该填对。

::: tip 版本化
同名制品可以有多个版本。挂载时选具体版本，这样「换了资料」是一次可追溯的版本切换，而不是悄悄覆盖。
:::

## 常见问题

| 现象 | 处理 |
|---|---|
| 侧边栏找不到这一页 | v0.0.1 未暴露入口，直接访问 `/agents/config` |
| 「暂无可用知识包」 | 平台里没有 `knowledge` 类型的制品，需要先把资料包入库 |
| 挂了包但 VM 里没有 | ① 等一次心跳 ② VM 能否访问制品 URI ③ sha256 是否匹配 ④ 看 VM 内 `journalctl -u agent-manager` |
| 知识包同步失败会不会影响 agent | 不会。同步是 best-effort，失败只是降级跳过 |
| 新建配置点不了 | v0.0.1 未开放，先用已有配置 |
