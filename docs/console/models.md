# 模型管理

> 模型调度台 → 模型管理 · 需要 <span class="ap-badge admin">admin</span>

管理上游供应商提供的模型配置（鉴权、速率与计费参数），控制平台侧的接入门禁与健康探测。

## 两层结构

```
模型（Model）                      ← 平台侧的一条登记，绑定一个模型网关
  └─ 供应商模型规格（Spec）×N       ← 同名模型的多个上游实例，用于负载与容灾
       provider · 上游模型原名 · API Base · API Key · 限流 · 单价 · 健康状态
```

一条模型下挂多个 spec，就能把同一个逻辑模型指向多个上游端点（不同区域、不同实例），由网关按路由策略分派。

## 新建模型

点 **新建模型**，向导分三步：

<ol class="ap-steps">
<li><strong>基本</strong> —— 模型名称（大小写字母、数字、中划线与点，2–64 字符）、所属模型网关、所属组织。</li>
<li><strong>供应商模型</strong> —— 添加一个或多个 spec：供应商分类、上游模型原名、API Base、API Key、Tags、限流与单价。可点 <strong>测试连接</strong> 逐个验证。</li>
<li><strong>确认并提交</strong> —— 复核全部字段后提交创建。</li>
</ol>

### 关键字段

| 字段 | 说明 |
|---|---|
| 模型名称 | 平台内的唯一标识，也是路由挑选模型时看到的名字。**编辑时不可更改** |
| 供应商分类 | LiteLLM 的 provider，如 `openai` / `azure` / `vllm` / `ollama` |
| 上游模型原名 | 供应商侧的真实模型名，如 `gpt-4o-mini`、`Qwen2.5-72B-Instruct` |
| API Base | 上游服务地址。内网私有模型服务同样填这里 |
| API Key | **后端加密入库，前端不再显示**。编辑时留空 = 保持原密钥，填新值 = 轮换 |
| 限流类型 | Token 限制（TPM）/ 请求数限制（RPM）/ 组合限制 |
| 每分钟 Token 数（TPM） | 该模型的 token 速率上限 |
| 每分钟请求数（RPM） | 该模型的请求速率上限 |
| 单价（/token） | 计量中心据此估算成本。**不填则该模型的费用算不出来** |
| 所属组织 | 行级字段，编辑模式下不可改 |
| 创建后立即启用 | 勾选则保存即生效 |

::: tip 一定要填单价
仪表盘的「本月费用」、计量中心的成本估算都依赖单价。缺价格时的行为可在[计量设置](/observability/metering-settings)里选择：标记为待配置 / 按 0 计算并告警 / 拒绝生成费用记录。
:::

## 健康状态

每个 spec 有独立的健康状态：

| 状态 | 含义 | 常见处理 |
|---|---|---|
| 健康 | 探测成功 | — |
| 降级 | 部分探测失败或延迟异常 | 观察；检查上游负载 |
| 熔断 | 连续失败已被摘除 | 修好上游后点「解除熔断」 |
| 未探测 | 从未探测过 | 点「探测」或「检测健康」 |

行内操作：**探测**、**熔断**（手工摘除）、**解除熔断**。

::: warning 熔断是保护不是故障
被熔断的 spec 不再接收流量，路由会按降级链切到其他模型。修复上游后需要**手工解除**，不会自动恢复。
:::

## 列表与批量操作

| 能力 | 说明 |
|---|---|
| 筛选 | 按状态（全部 / 启用 / 未启用）、按模型网关 |
| 排序 / 过滤 | 各列表头支持 |
| 行内操作 | 探测 · 检测健康 · 编辑 · 应用至… · 启用 · 禁用 · 删除 · 管理供应商模型 |
| 批量操作 | 批量启用 · 批量禁用 · 批量删除 |

**管理供应商模型** 打开抽屉，在里面增删改该模型下的 spec 列表。

## 与路由的关系

模型登记好之后，还要在[网关路由](/console/routes)里把它挑进某条路由，智能体才能通过路由名调用它。**只登记模型、不建路由，调用会找不到模型。**

## 常见问题

| 现象 | 处理 |
|---|---|
| 测试连接失败 | API Base 是否控制面可达；API Key 是否有效；provider 分类是否与上游匹配 |
| 保存后状态一直「未探测」 | 点「检测健康」主动触发一次 |
| 编辑时看不到 API Key | 正常 —— 密钥加密入库不回显。留空即保持不变 |
| 计量里这个模型没有费用 | 单价未配置 |
