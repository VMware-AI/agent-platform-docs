# 智能体市场

> 智能体中心 → 智能体市场 · 需要 <span class="ap-badge admin">admin</span>

从已验证的 OVA 模板快速创建智能体，支持 OpenClaw、Hermes、OpenCode、QCoder、小怪等多种架构。这一页是**模板目录**，部署动作从这里发起。

## 模板卡片

每张卡片代表一个**模板族**，展示：

- 名称、类型徽标与描述
- **预装工具** · **预装技能** · **适用场景**
- 当前版本与版本总数（`当前 v1.2 · 共 3 个版本`）
- 版本下拉：可切换到历史版本

卡片操作：**查看详情**（含版本历史）、**部署智能体**。

工具栏支持按名称搜索、按类型筛选。

## 新增智能体模版

点 **新增智能体模版**。表单有两种模式：

### 默认模式 —— 从内容库挑

<ol class="ap-steps">
<li>选 <strong>资源池</strong>（已接入的 vCenter）。</li>
<li>选 <strong>内容库</strong>（该 vCenter 上的 Content Library）。</li>
<li>选 <strong>OVA 模板</strong>（内容库里的 OVF/OVA 项）。</li>
<li>填名称、类型、初始版本号、描述。</li>
<li>可选：逐行填「支持的工具」「适用场景」「预装技能」，每行一条。</li>
<li>提交。</li>
</ol>

### 自定义模式 —— 浏览 vCenter VM 模板

点「自定义模式（浏览 vCenter 模板）」切换，改为直接从 vCenter 的 VM 模板列表里挑，或手工填写 **OVA 标识符**（后端用它在 Content Library 里查找 OVF 模板）。

| 字段 | 说明 |
|---|---|
| 智能体名称 | 模板族显示名 |
| 智能体类型 | OpenClaw / Hermes / 小怪 / QCoder / OpenCode |
| 初始版本号 | 该族的第一个版本 |
| OVA 标识符 | 内容库中的 OVF 模板标识 |
| 描述 | 卡片上的说明文字 |
| 支持的工具 / 适用场景 / 预装技能 | 每行一条，展示在卡片上 |

::: tip 下拉为空怎么办
- 「资源池」为空 → 还没[接入资源池](/console/resource-pools)
- 「内容库」为空 → 资源池未测试连接或未同步完成
- 「OVA 模板」为空 → 该内容库里没有 OVF/OVA 项
- 提示「vCenter 不可达」→ 回资源池页重新测试连接
:::

## 版本管理

同一个模板族可以有多个版本，对应不同的 agent 镜像迭代。部署时可选具体版本（默认最新）。「查看详情」里能看到完整的**版本历史**。

新版本 agent 发布后的推荐做法：

1. 在这里给该族加一个新版本（指向新的 OVA）
2. 新部署的实例自然用新版本
3. 已存在的实例通过[版本更新](/agent-vm/upgrade)在 VM 内升级，不需要重建

## 删除模板

点删除后需要**输入模板名称**确认。

::: warning 被引用的模板删不掉
已有智能体实例引用的模板无法删除。删除会连同该族的**所有版本**一起移除，操作不可撤销。
:::
