# 智能体市场

> 智能体中心 → 智能体市场 · 需要 <span class="ap-badge admin">admin</span>

从已验证的 OVA 模板快速创建智能体，支持 OpenClaw、Hermes、OpenCode、QCoder、小怪等多种架构。这一页是**模板目录**，部署动作从这里发起。

## 模板族与版本

```
模板族 OvaTemplateFamily            ← 一类智能体，卡片上看到的就是它
├─ 名称 / 类型 / 描述
├─ 预装工具 / 预装技能 / 适用场景     ← 展示在卡片上，帮使用者选型
├─ 图标形状 / 图标配色
└─ 版本 OvaTemplateVersion ×N       ← 每个版本指向内容库里的一个 OVA
     版本号 / OVA 标识符 / 备注 / OVF 属性
```

部署时选**族** + 选**版本**。

## 模板卡片

每张卡片展示：

- 名称、类型徽标与描述
- **预装工具** · **预装技能** · **适用场景**
- 当前版本与版本总数（`当前 v1.2 · 共 3 个版本`）
- 版本下拉，可切到历史版本

卡片操作：**查看详情**（含完整版本历史）、**部署智能体**。

工具栏支持按名称搜索、按类型筛选（全部 / OpenClaw / Hermes / 小怪 / QCoder / OpenCode），列表分页。

## 新增智能体模版

点 **新增智能体模版**。表单有两种模式。

### 默认模式 —— 从内容库挑

<ol class="ap-steps">
<li>选 <strong>资源池</strong>（已接入的 vCenter）。</li>
<li>选 <strong>内容库</strong>（该 vCenter 上的 Content Library）。</li>
<li>选 <strong>OVA 模板</strong>（内容库里的 OVF/OVA 项）。</li>
<li>填名称、类型、初始版本号、描述。</li>
<li>逐行填「支持的工具」「适用场景」「预装技能」—— <strong>每行一条</strong>。</li>
<li>选图标形状与配色（蓝 / 紫 / 橙 / 绿 / 红 / 青）。</li>
<li>提交。</li>
</ol>

### 自定义模式 —— 浏览 vCenter VM 模板

点「自定义模式（浏览 vCenter 模板）」切换，改为直接从 vCenter 的 **VM 模板**列表里挑，或手工填写 **OVA 标识符**（后端用它在 Content Library 里查找 OVF 模板）。

适用于模板不在内容库、而是以 VM 模板形式存在的环境。

### 字段说明

| 字段 | 说明 |
|---|---|
| 智能体名称 | 模板族显示名 |
| 智能体类型 | OpenClaw / Hermes / 小怪 / QCoder / OpenCode |
| 初始版本号 | 该族的第一个版本 |
| OVA 标识符 | 内容库中的 OVF 模板标识；后端据此定位模板 |
| 描述 | 卡片上的说明文字 |
| 支持的工具 / 适用场景 / 预装技能 | 每行一条，展示在卡片上 |
| 图标形状 / 配色 | 卡片视觉区分 |

::: tip 卡片信息是给「选型的人」看的
「预装工具 / 技能 / 适用场景」不影响任何功能，纯展示。但它决定了管理员在几十张卡片里能不能快速挑对 —— 值得认真填。写清楚这个 agent 擅长什么、装了哪些 CLI、适合哪类任务。
:::

::: warning 下拉为空的排查顺序
- 「资源池」为空 → 还没[接入资源池](/console/resource-pools)
- 「内容库」为空 → 资源池未测试连接或未同步完成
- 「OVA 模板」为空 → 该内容库里没有 OVF/OVA 项
- 提示「vCenter 不可达」→ 回资源池页重新测试连接
:::

## OVF 属性

每个模板版本会带出它自己的 **OVF 属性**清单，每一项有：

| 属性 | 说明 |
|---|---|
| key / label | 属性键与显示名 |
| type | 数据类型 |
| 默认值 | 未填时使用 |
| 描述 | 用途说明 |
| 是否必填 | 必填项部署时不能留空 |
| 是否密码型 | 密码型属性在界面上遮蔽显示 |
| 可选值 | 有枚举时给出下拉 |
| 分类 | 属性分组 |

部署时可以逐项覆盖这些属性，实例创建后也能在[配置面板](/console/agents#配置面板)的「vApp 部署参数」里增删改。

::: tip 密码通过 OVF 属性传
部署向导里设置的 VM 登录密码，就是通过 OVF / vApp 属性注入的，不进镜像。
:::

## 版本管理

同一个模板族可以有多个版本，对应 agent 镜像的迭代。「查看详情」里能看到完整**版本历史**。

新版本 agent 发布后的推荐做法：

<ol class="ap-steps">
<li>把新 OVA 传进内容库。</li>
<li>在这里给该族<strong>加一个新版本</strong>，指向新的 OVA 标识符，备注里写清改了什么。</li>
<li>新部署的实例自然用新版本（部署时默认选最新）。</li>
<li>已有实例走 <a href="/agent-vm/upgrade">版本更新</a> 在 VM 内升级 —— <strong>不需要重建</strong>，工作数据不丢。</li>
</ol>

::: warning 加版本 ≠ 已有实例自动升级
模板版本只影响**新部署**的实例。存量实例必须显式下发版本更新。
:::

## 删除模板

点删除后需**输入模板名称**确认。

::: danger 被引用的模板删不掉
已有智能体实例引用的模板无法删除。删除会连同该族的**所有版本**一起移除，操作不可撤销。想下线某个族又暂时不能删时，先把它从日常选型清单里去掉即可。
:::

## 常见问题

| 现象 | 处理 |
|---|---|
| 卡片列表为空 | 还没登记任何模板族，点「新增智能体模版」 |
| 部署出来的 VM 起不来 | OVA 模板本身有问题，或必填 OVF 属性没给值；到 vCenter Console 看 VM 启动日志 |
| 想换 OVA 但保留卡片信息 | 给同一个族加新版本，不要重建族 |
| 模板删不掉 | 有实例在引用；先回收那些实例 |
| 同一个 agent 装了两次族 | 合并成一个族的两个版本更合理 —— 卡片会少一半，选型不迷路 |
